# あなたの設定ファイル

このファイルに書いた内容をもとに、AIがあなたらしいnote記事を書きます。

> **手で埋めなくて大丈夫です。** セットアップのときにAIが質問して、代わりに書き込んでくれます。
> このファイルを直接開くのは、あとから設定を見直したくなったときだけで十分です。

書き方に迷ったら、下の「記入例」をそのまま真似して、自分の言葉に置き換えるだけで大丈夫です。
空欄のまま残しても動きますが、埋めるほど「自分が書いた文章」に近づきます。

---

## 1. あなたのこと

| 項目 | 内容 |
|---|---|
| 名前・ペンネーム | aku |
| noteのアカウント名 | aku |
| 発信のテーマ | 歯科衛生士としての長年の勤務経験 |
| 今の仕事・立場 | 現役の歯科衛生士として勤務中 |
| この分野の経験 | 歯科衛生士として長年にわたり勤務 |

> **記入例**
> 名前：たなか／noteアカウント：tanaka_note
> 発信のテーマ：AIを使った副業の始め方
> 今の仕事・立場：会社員をしながら副業でライターをしています
> この分野の経験：副業歴2年。月に5万円くらいの収入があります

## 2. 誰に向けて書くか

| 項目 | 内容 |
|---|---|
| 年代・性別 | 特に決めていない |
| どんな状況の人か | 特に決めていない |
| 抱えている悩み | 特に決めていない |
| 記事を読んだあと、どうなってほしいか | 「自分にもできそう」と思って一歩動いてもらう |

> **記入例**
> 年代：30〜40代
> どんな状況の人か：会社員。副業を始めたいが、何から手をつけるか分からない
> 悩み：時間がない。パソコンが得意ではない。失敗するのが怖い
> どうなってほしいか：「これなら自分にもできそう」と思って、今日ひとつ動いてもらう

## 3. 文章のトーン

| 項目 | 内容 |
|---|---|
| 一人称（自分の呼び方） | 私 |
| よく使う語尾 | ですます調（〜をお伝えします／〜のはずです、など丁寧で柔らかい言い切り） |
| 避けたい言い回し | 特になし |
| 敬語のレベル | 丁寧だが堅くない。専門用語を避けて、噛み砕いて説明する |

> **記入例**
> 一人称：僕
> よく使う語尾：〜なんです／〜なんですよね
> 避けたい言い回し：「だから」は使わず「なので」にする。堅い専門用語は言い換える
> 敬語のレベル：ですます調。友だちに説明するくらいの距離感

### あなたが書いた文章のサンプル

過去に書いた文章を、**200字ほどそのまま貼ってください。** AIがこれを読んで書き方を真似します。
これが一番効きます。面倒でも、ここだけは埋めることをおすすめします。

```
なぜ40代からの歯茎のサインを見過ごしてはいけないのか。ご自身の歯茎の状態をセルフチェックする方法。歯科衛生士がすすめる、歯周病を防ぐための正しい歯磨きの型。セルフケアだけでは難しい場合の治療の選択肢「ブルーラジカル」を、専門用語を避けながらお伝えします。読み終える頃には、「なんとなく不安」だった歯茎の状態が、「何をすればいいか分かって、少し安心できる」状態に変わっているはずです。

60歳からでも「定年なし」で働ける職場の見分け方。対象読者：60歳目前で再就職・転職先を探している方。23年勤めた歯科医院を辞め、60歳定年での契約社員化、そして10ヶ月での退職を経て、今は定年のない職場でやりがいを持って働く私が、応募前にできる具体的な見分け方をお伝えします。
```

## 4. 自己開示に使えるエピソード

記事の説得力は「自分の失敗談」で決まります。使えそうな話を3つほど書いてください。
うまく書こうとしなくて大丈夫です。箇条書きで十分です。

- 例：最初の3ヶ月、まったく成果が出なくて辞めようと思った
- 例：高い教材を買ったのに、結局使わずに終わった
- 例：作業に10時間かかっていたものが、やり方を変えたら2時間になった

```
1. ホワイトニングの施術で歯肉の保護剤が足りず、薬剤が歯肉に触れて白くなってしまったことがある
2.
3.
```

## 6. 売る記事のこと（有料note用・ここがいちばん大事）

有料noteは、買う前に読める**無料パート**と、買った人が読む**有料パート**に分かれます。

| 項目 | 内容 |
|---|---|
| 何を教える記事か | 歯科衛生士の知識を活かした「口元まわりの美容」（歯のホワイトニング・ほうれい線対策） |
| 読み終わった人ができるようになること | その日からできるホワイトニング・ほうれい線対策を、自分で始められる |
| 価格帯（いくらで売りたいか） | 980円 |
| 購入者特典（付けるときだけ書き換える） | なし |

> **記入例**
> 何を教える記事か：AIで議事録を10分で作る手順
> 読み終わった人ができるようになること：次の会議から、議事録を10分で出せる
> 価格帯：980〜1,500円
> 購入者特典：なし

### 無料で見せる範囲

**この記事の答えそのものは、無料パートで見せます。** 隠すと読まれません。有料にするのは「具体的な手順」です。

| 項目 | 内容 |
|---|---|
| 無料で見せてよいところ | おまかせ |
| 有料にしたいところ | おまかせ |

> **記入例**
> 無料で見せてよいところ：なぜ1時間かかるのか／全体の3ステップ／結論（音声を直接AIに渡さない）
> 有料にしたいところ：録音のしかた／文字にする手順／指示文の全文／確認する箇所

**決まっていなければ「おまかせ」と書いてください。** AIが記事の内容から判断して、どこで切るかを提案します。

## 6-3. 返金について（有料note用）

noteには、買った人が**購入から24時間以内**に返金を申請できる仕組みがあります（2026年8月時点）。

**何も設定しないと「返金申請を受け付ける」状態で公開されます。**

| 項目 | 内容 |
|---|---|
| 返金申請を受け付けるか（受け付ける／受け付けない） | 受け付ける |

> どちらでも構いませんが、**知らないまま公開しない**でください。公開設定の画面で1回確認します。
> 受け付けない設定にすると、買う人の画面に「返金不可」と表示されます。

## 6-4. 使ってはいけない表現（有料note用）

お金を受け取る記事なので、書けないことがあります。**次は全員共通で禁止です。**

絶対／必ず／誰でも／100%／確実に／保証／今だけ／限定／やらないと損／人生が変わる

収入の断定（「月5万稼げます」）も書けません。「僕の場合は3ヶ月目に5万円でした」のように、自分の実際の話に置き換えます。

| 項目 | 内容 |
|---|---|
| このジャンル特有で気をつけること（あれば） | 歯科・美容の話題なので、効果を断定しない（薬機法）。「必ず白くなる」等は書かず、自分の実際の経験・体感として書く |
| 書きたくない話題・触れられたくないこと（無ければ「なし」） | なし |

> 記入例：健康・医療の話題なので、効果を断定しない（薬機法）

## 7. 画像の好み（任意・空欄でOK）

**先に `画像の見本` フォルダを開いてください。** 実物を見てから選ぶと決めやすいです。
空欄なら、型Aとオレンジの初期設定で作ります。

### 画像づくりの道具

| 項目 | 内容 |
|---|---|
| Codexを入れたか（入れた / 入れていない） | 入れていない |

> セットアップのときにAIが書き込みます。「入れていない」と書いてあれば、以後は毎回聞かれずに図解だけを作ります。
> あとから入れたときは、ここを「入れた」に直してください。

### サムネイル（見出し画像）の型

| 項目 | 内容 |
|---|---|
| どの型で作るか（A / B / C） | |

- **A：完全ガイド型** … 迷ったらこれ。ノウハウ記事・手順記事・まとめ記事のほぼ全部に使えます
- **B：ロードマップ型** … 「5日間で」「3ステップで」など、日数やステップで区切る記事に
- **C：特典型** … 特典つきの記事、数字を前面に出す記事に

> 記事ごとに変えることもできます。「今回はBで」と伝えるだけです。

### 色

色は「#」で始まる6桁の記号（カラーコード）で書きます。分からなければ空欄で大丈夫です。

| 項目 | 内容 |
|---|---|
| メインの色（アクセント） | |
| 文字の色 | |
| 背景の色 | |
| 補足文字の色 | |

> **記入例**
> メインの色：#E8703A（オレンジ）
> 文字の色：#1B2A4A（濃紺）
> 背景の色：#FDF8F0（クリーム）
> 補足文字の色：#9CA3AF（グレー）

> **色を決めるコツ**
> 記事全体で同じ色を使うほど「その人らしさ」が出ます。迷ったら、すでに使っているSNSのアイコンや
> ヘッダーの色から1色選んで「メインの色」に入れてください。それだけで揃って見えます。

### 記事に差し込む画像

| 項目 | 内容 |
|---|---|
| 人物のイラストを入れるか（入れる / 入れない） | 入れない（Codex未導入のため作れない） |
| 操作画面のスクリーンショットを使うか（使う / 使わない） | おまかせ |
| 入れたくないもの（あれば） | 特になし |

> **記入例**
> 人物のイラスト：入れる（30〜40代の男性。読者と同じ年代がいい）
> 操作画面：使う（登録方法を説明する記事が多いので）
> 入れたくないもの：顔写真、キラキラした装飾

> **人物のイラストについて**
> 入れると記事がやわらかくなり、読み進めてもらいやすくなります。
> 数字や手順が中心の発信なら、無しでもすっきりして読みやすいです。
> 人物のイラストは、Codexを入れた場合だけ作れます。

## 9. あなたらしさを深める（任意・空欄でOK）

**ここは全部空欄でも記事は作れます。** ただし、埋めるほど「その人が書いた文章」に近づきます。
あとから思い出したときに書き足す使い方で構いません。

### 話し方のクセ

| 項目 | 内容 |
|---|---|
| 口ぐせ・よく使う言い回し | |
| 説明するときによく使うたとえ | |

> **記入例**
> 口ぐせ：「ここ、けっこう大事なんですけど」「正直に言うと」「僕も最初はそうでした」
> よく使うたとえ：料理にたとえる（材料を先に並べる／レシピどおりにやる）

> **これが一番効きます。** 語尾だけそろえてもAIっぽさは消えません。
> その人が実際に口に出す言い回しが2〜3個あるだけで、文章の顔が変わります。

### あなたの背景

| 項目 | 内容 |
|---|---|
| この分野に入ったきっかけ（いつ・何が） | |
| 今でも苦手なこと・できないこと | |

> **記入例**
> きっかけ：2年前、残業続きで子どもの寝顔しか見られなかったとき、AIを触りはじめた
> 今でも苦手なこと：プログラミングは全然わからない。エラーが出ると今でも固まる

> **できないことを書くほど、読者は安心します。** 完璧な人の話は、自分ごとになりません。

### 読者との関係

| 項目 | 内容 |
|---|---|
| 読者からよく聞かれる質問（3つまで） | |

> **記入例**
> よく聞かれる質問：どのAIを使えばいい？／無料版でもできる？／どのくらいで結果が出る？

> よく聞かれる質問は、**そのまま章の見出しになります。**
