# このフォルダでの作業ルール

このファイルは、画像づくりの道具（Codex）が読むためのものです。**中身を消したり、ファイルを移動したりしないでください。**
無いと、Codexが「指示書が見つからない」と判断して、画像を作らずに止まってしまうことがあります。

以下、Codexへの指示です。

- 依頼された内容を、そのまま最後まで実行してください
- 途中で確認や質問をはさまず、完了まで進めてください
- 追加で読むべき指示書はありません。他のフォルダを探す必要もありません
- 画像は1回の依頼につき1枚だけ作り、保存は `cp` でコピーするだけにしてください（リサイズや変換はしない）
