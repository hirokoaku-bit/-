# はじめに読む注意書き

このキットを使う前に、ここだけは目を通してください。**2分で読めます。**

---

## 1. このキットが、あなたの代わりにやること

- noteの**下書きを作るところまで**を自動で行います
- そのために、**あなたのパソコンの中でブラウザを動かし、あなたのnoteアカウントにログインした状態で操作します**

**公開ボタンは押しません。** 何を世に出すかは、最後まであなたが決めます。

**あなたがターミナル（黒い画面）を開くことはありません。** コマンドはClaudeが実行します。
実行の前には「このコマンドを実行してもいいですか」という確認が出るので、内容を見て許可してください。
分からないときは、そのまま「これは何をするコマンドですか」と聞けば説明してくれます。

## 2. noteの規約について

noteは、規約や仕様をときどき変えます。**2026年9月時点で、note公式の利用規約に、この種の自動操作を直接禁じる条文は見当たりませんでした。**
ただし次の点は、はっきりさせておきます。

- 私たちはnoteの許可を得てこのキットを作っているわけではありません
- 規約は変わります。**使う前に、ご自身で最新の規約を確認してください**
  → [note 規約のページ](https://terms.help-note.com/) を開き、「ご利用規約」を読んでください
- 短時間に何十本も投稿するような使い方はしないでください。**1日に何本も自動で流す道具ではありません**
- 万一アカウントに何かあった場合、**責任を負えるのはあなただけ**です

不安があるなら、**下書きまで自分の手で作り、このキットは記事と画像を作る部分だけに使う**という選び方もできます。

## 3. どこに何が送られるか

記事を作る過程で、**あなたが書いた内容や指示は、AIの提供元に送られます。**

| 何が | どこへ | いつ |
|---|---|---|
| 記事のテーマ・構成・本文・`profile.md` の中身 | Anthropic（Claude） | 記事を作っている間ずっと |
| 画像に描く文言・デザインの指示 | OpenAI（Codex／ChatGPT） | 画像を作るときだけ |
| 記事の本文・画像・タイトル | note | 下書きを入れるときだけ |

つまり、**`profile.md` に書いたことは、AIの提供元に渡ります。** 次のものは書かないでください。

- パスワード、クレジットカード番号、マイナンバー
- 他人の個人情報（お客さんの氏名・連絡先など）
- 人に知られて困る内容

「書きたくない話題・触れられたくないこと」の欄は、**記事に出さないための指定**であって、AIに渡らないという意味ではありません。

## 4. あなたのパソコンに残るもの

| 残るもの | 場所 | 中身 |
|---|---|---|
| noteのログイン状態 | `note-draft/storage/note-auth.json` | パスワードではなく「ログイン済みの証明書」 |
| 実行のログ | `note-draft/logs/` | 手順と件数（本文の全文は残しません） |
| 画面のスクリーンショット | `note-draft/screenshots/` | 入稿したときの画面 |
| 記事と画像 | `note-draft/articles/` | あなたが作った記事 |

**このフォルダを誰かに渡さないでください。** `storage` の中身があれば、他人があなたのnoteを操作できます。
人に渡すときは、`storage/` `logs/` `screenshots/` の中身を消してからにしてください。

## 5. やめたくなったら

いつでも、あとかたなく消せます。

> **Claudeに「yuryo-kit-liveをやめたい」と伝えてください。** それだけで、下の手順を実行してくれます。

自分で操作したい方は、次を上から順に。（Macはターミナル、WindowsはPowerShell）

**Macの場合**（ターミナルで実行。どちらもゴミ箱に入るだけなので、あとから戻せます）

```bash
mv ~/.claude/skills/yuryo-live-note ~/.claude/skills/yuryo-live-image ~/.claude/skills/yuryo-live-toukou ~/.Trash/
```

```bash
mv ~/yuryo-kit-live ~/.Trash/
```

**Windowsの場合**（PowerShellで実行。ユーザーフォルダの直下に「yuryo-kit-live-削除予定」というフォルダを作ってまとめます）

```powershell
New-Item -ItemType Directory -Force "$HOME\yuryo-kit-live-削除予定" | Out-Null
```

```powershell
Move-Item "$HOME\.claude\skills\yuryo-live-note","$HOME\.claude\skills\yuryo-live-image","$HOME\.claude\skills\yuryo-live-toukou" "$HOME\yuryo-kit-live-削除予定\" -ErrorAction SilentlyContinue
```

```powershell
Move-Item "$HOME\yuryo-kit-live" "$HOME\yuryo-kit-live-削除予定\"
```

最後に、`C:\Users\あなたの名前\yuryo-kit-live-削除予定` フォルダを右クリックして削除してください（ごみ箱に入ります）。

これで、AIは元の状態に戻ります。**noteに作った下書きは消えません。** 不要なものは、noteの下書き一覧から手で消してください。

以前から自分でnote系の手順書を使っていて、導入のときに控えを取った方は、`~/.claude/skills-backup` から戻せます。

## 6. できないこと・保証しないこと

- **記事の内容の正しさは保証しません。** AIは事実を調べてから書きますが、間違えます。**出す前に必ず自分で読んでください**
- **公開後の反応・収益は保証しません**
- noteが画面デザインを変えると、入稿が止まることがあります（直し方は `note-draft/README.md`）
- Windowsは**ベータ対応**です。動作確認の中心はMacです
- このキットは**個人が作ったもの**で、noteともAnthropicとも関係がありません

## 7. 困ったときの相談先

このキットのことは、**Claudeにそのまま聞いてください。** 画面に出ている文章をコピーして貼れば、たいてい進みます。

noteのアカウント自体のこと（ログインできない、記事が消えた等）は、[noteのヘルプ](https://www.help-note.com/) に問い合わせてください。

公式LINEからご連絡ください。
