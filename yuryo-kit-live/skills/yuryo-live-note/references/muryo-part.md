# 無料パート（買う前に読まれる部分）を書く

**型の正は `honnin-kata.md` の工程2。** この文書はその実行手順。食い違ったら honnin-kata を優先する。

## 書く順番（重要）

**無料パートは、有料パートを書き終えてから書く。**

本人の結論。有料パートが出来上がってからのほうが、何を見せるべきかが見える。

先に書きたくなっても、順番を守る。

## 役割

**買う理由を作る場所。** いい話をする場所ではない。

読者はここで判断する。自分の話か／この人は信用できるか／続きで何ができるようになるか。

**煽って売らない。** 判断材料を渡して、選んでもらう。

## 置くのはこの4つ

順番もこのとおり。

### 1. 悩みの言語化（いちばん大事）

読む人が**言葉にできていない状態を、代わりに言葉にする**。

ここで「自分のことだ」と思ってもらえないと、以降は読まれない。無料パートの成否の8割はここ。

書き方：

- 読者の独り言をそのまま置く（「またこれか、って思ったんですよね」）
- 詰まっている状態を具体的な場面で描く（「書いては消して、気づけば1週間、下書きが空のまま」）
- 数字から入る（「応募20件出して、返信は1件でした」）

やらないこと：

- 「近年〜」「昨今〜」で始める
- 「この記事では〜を解説します」で始める
- 読者を責める（「行動しないから稼げないんです」）


> **自己開示は `profile.md` の「9. あなたらしさを深める」から引く。**
> 「この分野に入ったきっかけ」に**いつ**が書いてあれば、その時期をそのまま書く。時期が入ると本当の話になる。
> 「今でも苦手なこと」があれば、そこで一度弱みを見せる。完璧な書き手に見せない。
> **空欄なら作らない。** 憶測でエピソードを書かない。

### 2. 全体像

これから何をするのかの地図。**工程がいくつあるか**を示す。

- 「この記事で通る7つの工程」のように、数を先に出す
- 各工程を1行ずつ並べる
- 図を1枚入れる

### 3. 結論

**答えそのもの。隠さない。**

ここが本人の型でいちばん誤解されやすい部分。出し惜しみしない。

- 答えは出していい
- **手順は出さない**

この線引きが無料パートのほぼすべて。答えを見せても売れる。むしろ、隠すと読まれない。

### 4. この先の予告

有料パートで何が手に入るか。**目次を見せてしまってもいい。**

良い例：

```
ここから先で渡すもの

- 応募文のテンプレ3種（そのままコピーして使えます）
- 返信率が落ちたときに見る3つの数字
- 単価を上げたときの交渉文（全文）
- よくある失敗7つと、それぞれの回避法
```

悪い例：

```
ここから先は有料です。続きが気になる方はぜひご購入ください。
```

## 冒頭に並べて書く（得られること／扱わないこと）

**低評価と返金を減らす、いちばん効く一手。**（honnin-kata 工程6）

無料パートの中（1と2のあいだ、または2の直後）に置く。

```
**この記事で得られること**
- （具体的に）
- （具体的に）

**この記事では扱わないこと**
- （別記事で扱うもの）
- （範囲外のもの）
```

扱わないことを書くと売れなくなりそうに見えるが、実際は逆。輪郭がはっきりして、必要な人に届く。

## 有料ラインの切り位置

**「分かった」の直後、「やってみよう」の直前。**

判定のしかた：無料パートだけを読み返して、読み終わったときに「で、どうやるの？」と自分で思えたら、そこが切り位置。**すっきり終わってしまったら、後ろすぎる。**

切る直前に、続きが具体的に何かを1行書く。

- 良い：ここから先は、実際に使っている応募文のテンプレを3種類とも全文出します
- 悪い：続きは有料パートで

## やってはいけない2つ（本人の失敗）

### 全部隠す

もったいぶって核心を避け、「詳しくは本編で」「ここから先が本題です」と何度も書くと、**有料ラインまでたどり着く人が減る**。

> 何も書いていない文章を、人は最後まで読まない。

### 手順まで全部出す

答えは出していいが、手順まで出すと買う理由が消える。

## 価格に触れるとき

価格が確定してから書く（SKILL.mdの工程順を守る）。

触れるなら1〜2行だけ。買わなくていい理由も一緒に置く。

- 値段は◯◯円にしました（理由を1行。時間・手間・失敗の回避で説明する）
- 無料部分だけでも◯◯はできます。それで足りるならそれでOKです

やらないこと：

- 「本来◯万円のところ今だけ◯円」（根拠のない二重価格は景表法上の問題になる）
- 「値上げ予定」で急かす（実際に予定があり、正確に書く場合のみ）
- 「買わないと損」

## 文体

`honbun.md` の文体ルールと同じ。一人称「僕」・短文・1段落2〜3行・同一語尾3連続禁止・「だから」禁止。

無料パートで特に気をつけること。

- 教材調で始めない
- 上から目線にしない（「重要なのは」「意識しましょう」）
- 焦らせない（「今すぐ」「今だけ」「手遅れになる前に」）

## 見出しの形

H3は疑問形を主体にする（honnin-kata「見出しの形」）。

- 書けないのは、文章がヘタだからでしょうか
- 有料ラインは、どこで切るのか

失敗談と結論だけ断定形にする。

## 文字数

`profile.md` の「6-2. 記事の長さ」の**無料パートの文字数**に従う。**上限で管理する**（下限だと書き足し続ける）。

## 画像

**無料パートの画像は2〜3枚。**

- 全体像の図（工程がいくつあるか1枚で分かるもの）
- 得られること／扱わないことの図（入れると効く）

本文中は `［図：〜］` のマーカーで置き、あとで差し替える。

**誘導の案内（公式LINEなど）は無料パートに入れない**（買う前に売り込みを重ねない）。

サムネイル（見出し画像）は別に1枚必ず作る。

## 出力前チェック

- 有料パートを書き終えてから書いたか
- 悩みの言語化から始まっているか（教材調で始まっていないか）
- 全体像で工程の数を示したか
- **結論を出したか**（隠していないか）
- 手順を出してしまっていないか
- 目次予告に中身が見えているか
- 得られること／扱わないことを並べたか
- 有料ライン直前の1行が具体的か
- 読み返して「で、どうやるの？」と思えるか（すっきり終わっていないか）
- 煽り（今だけ／限定／絶対／やらないと損／人生変わる）がないか
- 収益額・期間・再現性を断定していないか
- 1段落4行以上の箇所がないか
- 「だから」「以下の」「上記の」「重要なのは」「ポイントは」を使っていないか

## この工程の心構え

売り込む文章ではなく、**判断材料を並べる文章**を書く。

答えは見せる。手順は見せない。もったいぶらない。
