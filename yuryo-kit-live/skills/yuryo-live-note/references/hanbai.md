# 価格・返金・特典・法律まわりと販売設定

有料パートを書き終えたあと、無料パートを書く前の工程。**お金の設計**をここで固める。

決定するのはユーザー。こちらは案と根拠を出す。

## 1. 価格を決める

### 見る軸（この3つだけ）

**① 読者が飛ばせる手間**

この記事で読者が省ける時間・失敗・遠回りを、時間か金額に置き換える。

- 半年遠回りした分の手順を渡す → その半年に価値がある
- 自分で試して捨てた選択肢を先に潰す → 失敗のコストを消している

**② 現物の数**

有料パートに入れた現物（手順・テンプレ・基準・チェックリスト・失敗例・画面）の数。

現物が少ないのに高いと、返金と低評価が来る。

**③ profile.md の価格帯**

profile.md の「価格帯」の範囲に収める。範囲外にするなら理由を添えて提案する。

### 目安

| 中身 | 価格の考え方 |
|---|---|
| 読み物寄り・体験談中心 | 低め。無料noteとの差が小さいなら有料にしない選択もある |
| 手順＋テンプレが揃っている | 中くらい |
| 手順＋テンプレ＋判断基準＋失敗例＋画面が全部ある | 高め。ただし初めての1本は抑える |

**初めて売る1本は、迷ったら安いほうを選ぶ。** 実績とレビューが先。値上げはあとからできる。

### noteの価格の上限と手数料

- noteの有料記事には**販売価格の下限と上限**がある。会員種別によっても変わる
- 売上からは**決済手数料とプラットフォーム利用料**が引かれる。決済手段によって率が違う
- 振込にも手数料がかかる

**これらの数字は変わる。** 価格を決める前に、必ず note のヘルプセンターで最新の「販売価格」「手数料」を確認する（WebSearchで公式ヘルプを引く）。記憶で答えない。

確認したら、**手取りの概算**を出してユーザーに見せる。

```
販売価格：◯◯円
決済手数料と利用料を引いた手取り目安：約◯◯円（◯年◯月時点の公式ヘルプより）
```

### 出力の形（価格の工程で画面に出す）

```
推奨価格：◯◯円

理由
1. （読者が飛ばせる手間）
2. （現物の数）
3. （profile.md の価格帯との関係）

手取り目安：約◯◯円（◯年◯月時点）
```

そのうえで聞く。

> 価格は◯◯円でよいですか？

**ユーザーが別の金額を指定したら、そのまま従う。** 最適化しない。

## 2. 返金の方針を決める

**noteの返金の仕組み**（2026年8月時点・honnin-kata 工程6より）

- 購入者が返金を申請できるのは、**購入から24時間以内**
- 申請できるのは、書いた側が「返金申請を受け付ける」設定にしている記事のみ
- **何も変更しなければ「受け付ける」状態で公開される**（初期設定）
- 販売開始後に設定を変えても、変更前に買った人からの申請は受け付けられる
- ゲスト購入（会員登録なし）は返金の対象外

つまり、初期設定のままだと24時間の返金枠がついた状態で売ることになる。

受け付けない設定にすると、購入者側に「返金不可」と表示される。初めて買う人には引っかかることもある。

**どちらが良いかは考え方次第。ただし設定を知らないまま公開しない。** 公開設定の画面で1回確認する。

> 仕様は変わる。販売前に必ず公式ヘルプで最新を確認し、確認した時点を記事に添える。

### 返金を減らす一番の方法

仕組みより先に、**冒頭で期待を合わせる**。

低評価の原因は、中身の薄さより先に**期待のズレ**。「この記事で得られること」と「この記事では扱わないこと」を並べて書くと、不満はかなり減る（honnin-kata 工程6）。

## 3. 購入者特典（付けるなら）

profile.md に指定があるときだけ。

決めること。

- 特典の中身
- 受け取り方（記事末尾のリンク／LINEで合言葉／フォーム）
- 期限（付けるなら、実際に運用できる期限だけ）

やらないこと。

- 特典を煽りに使う（「今だけ特典付き」）
- 運用できない期限を書く
- 特典目当てで本編を薄くする

## 4. 法律まわり（必ず通す）

### 景品表示法

- 収益・成果を断定しない（「月◯万稼げます」「必ず」「誰でも」「確実に」「保証」）
- 体験談を使うときは、それが個人の体験であることが分かる形にする（「僕の場合は」）
- **根拠のない二重価格を書かない**（「本来◯万円のところ今だけ◯円」）。過去に実際にその価格で相当期間販売した事実がない限り書かない
- 「値上げ予定」は、実際に値上げする予定があるときだけ、時期を正確に書く

### 特定商取引法

- noteの有料記事は、note側の販売の仕組みに乗る形になる
- 自分でLINEやフォームへ誘導して**別途おかねを受け取る導線を作る場合**は、必要な表示が変わる。その形にするときは、ここで止めてユーザーに確認する

### 著作権

- 他人の有料noteや教材の中身を写さない。型を参考にしても言葉は独自にする
- 引用するときは出典を書き、引用が主にならないようにする
- 画面のスクリーンショットに他人の名前・アカウント・投稿が写っていないか確認する

### 個人情報

- スクリーンショットにメールアドレス・鍵・課金情報・他人の名前が写っていないか、貼る前に必ず目視する

### 記事に入れる但し書き（有料パートの締めの前に1つ）

```
この記事に書いた数字は、僕が実際にやったときのものです（◯年◯月時点）。
やり方や結果には個人差があります。
```

## 5. 販売設定チェックリスト（人が手でやる）

**note側の有料設定・価格入力・公開は代行しない。** 画面に出して、ユーザーに手で行ってもらう。

```
販売設定チェックリスト（noteの編集画面で行う）

1. 記事の種類を「有料」にする
2. 販売価格を ◯◯円 に設定する
3. 有料ラインを「（見出し名）」の直前に置く
4. 見出し画像が設定されているか確認する
5. 無料部分をプレビューで確認する（スマホ表示で見る）
6. 返金申請の受付設定を確認する
7. タグを設定する
8. 公開ボタンを押す（ここまで来たら公開）
```

**チェックリストを出したら、そこで工程は終わり。** 代わりに押さない。

## 6. 公開したあと

聞かれたときだけ案内する。

- **値上げ**：実績とレビューが溜まってから。値上げ前に「値上げします」と告知するなら、実際にその予定があるときだけ
- **追記**：内容が古くなったら追記する。追記日を明記すると信頼が上がる
- **購入者への連絡**：note上で購入者だけに追記を届ける方法があるか、公式ヘルプで確認してから案内する
- **感想が来たとき**：スクリーンショットで公開するなら、必ず本人の許可を取る

## この工程の心構え

値付けは営業ではなく、**約束の重さを決める作業**。

高く付けるほど、渡す現物と裏取りの精度を上げる。金額に見合わないと感じたら、値段ではなく中身を足す提案をする。
