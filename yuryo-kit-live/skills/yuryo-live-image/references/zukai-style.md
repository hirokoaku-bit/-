# 挿入図解の型（Codexで作る用）

記事の中に差し込む解説図の見た目。**サムネイルより本数が多いので、ここが記事全体の印象を決める。**

HTML/CSSで作る旧デザインは `design-system.md` にある。**混ぜないこと。**

## いちばん大事な前提

**素っ気ない図は「手抜き」に見える。** 白背景にカードを2枚置いただけの図は、情報としては正しくても、
記事の格を下げる。目指すのは**やわらかく親しみやすい情報デザイン**で、次の3つが要になる。

1. **背景をクリーム色にして、四隅に装飾を置く**（真っ白にしない）
2. **カードに影をつけ、中を「ラベル→見出し→点線→絵→説明帯」の5層で作る**
3. **下に必ずまとめ帯を置く**（電球アイコン＋「ポイント」＋黄色いマーカー線）

「フラットでミニマル、影なし、装飾なし」と書くと、必ず素っ気ない図になる。書かないこと。

## 色

> **`profile.md` の「入れたくないもの」が、この型の指定より優先。**
> ぶつかったら型のほうを削る（葉っぱ・小枝・ドット・人物イラストなど）。**プロンプトの【禁止】にその言葉をそのまま書く。**
> ただし、背景のクリーム色・カードの5層・まとめ帯の3つだけは、指定が無い限り残す（この3つが図の格を決めている）。

**`~/yuryo-kit-live/profile.md` の「7. 画像の好み」から引く。** 空欄なら下の初期値。

| 用途 | 初期値 |
|---|---|
| 背景 | `#FDF8F0`（クリーム）※サムネイルより一段濃い。理由は `SKILL.md` の「色の決め方」 |
| 主文字 | `#1B2A4A`（濃紺） |
| アクセント | `#E8703A`（オレンジ） |
| 淡いアクセント面 | `#FBE4CE` |
| 補足文字・「良くない側」 | `#9CA3AF`（グレー） |
| チェック・OK | `#7FBF9F`（緑） |
| マーカー線 | `#FFE08A`（黄） |

- 書体は太いゴシック体（日本語）。大見出しは極太
- アイコンは線画か、単色のフラットなもの。絵文字は使わない
- 比率は 16:9

## 全体の骨格（全部の図で共通の3段）

### 1. 背景（これを省くと素っ気なくなる）

- クリーム色の地。**真っ白にしない**
- 四隅に淡いオレンジと淡い黄土色の**有機的な丸い形**
- 左上と右下に**葉っぱと小枝**のイラスト（淡いオレンジ・淡い黄緑）
- 小さなドットを数個散らす

### 2. 上段：見出し（3点セット）

1. 極太ゴシックの大見出し（濃紺）。**キーワード1語だけアクセント色**
2. 見出しの左右に**手書き風の短い斜線を2本ずつ**
3. その下に**アクセント色の点線**を横に引き、**中央にひとまわり小さいサブ見出し**を置く

### 3. 中段：本体（下の型から1つ選ぶ）

カードを使う型では、**カードの中を必ず5層**で作る。

```
┌─────────────────┐
│ ラベル（角丸ピル・白抜き）      │ ← グレー＝良くない側／アクセント色＝良い側
│ 太字の見出し（濃紺）          │
│ ─ ─ ─ ─ ─ ─ ─ （点線の区切り）  │
│ イラスト or アイコン          │
│ ▔▔▔ 淡い色の帯＋小さな説明文 ▔▔ │
└─────────────────┘
```

カードは**角を大きく丸め、枠線なし、やわらかい影**。白地。

### 4. 下段：まとめ帯

- **白地にアクセント色の太い枠線**の角丸長方形（塗りつぶしにしない）
- 左端にアクセント色の丸＋白い**電球アイコン**
- その隣にアクセント色の**角丸ピル「ポイント」**（白抜き）
- 右に濃紺の極太文字でまとめ。**キーワードだけアクセント色にして、下に黄色のマーカー線**

## レイアウトの型

### 比較2カラム（いちばん使う）
白カードを左右に2枚。左＝グレーのラベル（これまで）、右＝アクセント色のラベル（これから）。
**2枚の間に太いアクセント色の右向き矢印**を置き、矢印の中に白抜きの短い文字を入れる。
左カードには困った表情の人物、右カードには笑顔で指を立てた人物のフラットイラストを入れると効く。

### 3ステップ（番号カード）
白カードを横に3枚。各カードの上部に**丸いアクセント色の番号バッジ**（①②③、白抜き数字）。
カードの間はアクセント色の矢印。中身は5層の作りに従う。

### チェックリスト
白い角丸の大枠1枚。中にアクセント色の丸いチェックマーク＋項目を縦に4行、点線で仕切る。
各行の右端に小さなアイコン。

### 4分割グリッド
白カード2×2。各カードに大きなアクセント色の数字＋短い見出し＋線画アイコン。

### チャット風
濃紺のヘッダーバーがついた白い角丸枠。中に吹き出しを交互に並べる
（AI＝グレー・左寄せ／自分＝淡いアクセント色・右寄せ）。下に入力欄。

### 順位バー
横長の帯を4本、上から濃いアクセント色→淡い→白へ。左に名称、右に役割。

### タイムライン
横一直線。左半分はアクセント色、右半分はグレー。境目にアクセント色の旗と日付。

### 積み上げ
下から上へ角丸の横長ブロックを3段。上へいくほど幅を狭める。淡いアクセント色。一番上に旗。

### 氷山
水平線を1本。上に小さいグレーの氷山、下に大きな淡いアクセント色の氷山（点線の輪郭、多角形の面）。
黒とアクセント色の角丸ラベルを、**細い引き出し線と小さな丸**で指す。

### 分解
左にぐちゃぐちゃに絡まった線の塊（グレー）、右にアクセント色の太い矢印、その右に角丸カードを縦4枚。

## ラベルの置き方（共通）

図の一部を指すときは、この形で統一する。

- ラベルは**角丸の塗りつぶし**＋**白抜きの太字**
- ラベルから対象へ**細い引き出し線**を引き、線の先に**小さな丸**を打つ
- 吹き出しの三角は使わない（引き出し線のほうが締まる）

## 文字の指定のしかた

プロンプトには、**画像に出す日本語を一字一句そのまま**書く。要約や言い換えをさせない。

```
【文字】日本語はすべて正確に、崩れずに描くこと。次の文言を一字一句そのまま描く：
- 大見出し「書き出しでつまずかない」（「つまずかない」だけオレンジ）
- サブ見出し「構成を先に作れば、手は止まらない」
- 左カードのラベル「これまで」
- 左カードの見出し「白紙から書き始める」
```

## 部品が欠けたとき

サムネイルと同じで、**要素の詰め込みすぎ**が原因。詳しくは `thumbnail-style.md` の
「部品が欠けたときの直し方」。図解では次の順に削る。

葉っぱ・ドット → 手書きの斜線 → 矢印の中の文字 → カード内のイラスト

**背景のクリーム色・カードの5層・まとめ帯は削らない。** この3つが図の格を決めている。

## 確認のポイント

生成後は必ず画像を開いて見る。

- [ ] 日本語が崩れていないか（似た別の字になっていることがある）
- [ ] **背景が真っ白になっていないか**（クリーム色になっているか）
- [ ] **カードに影がついているか**（枠線だけの平たいカードになっていないか）
- [ ] **まとめ帯があるか**（電球・ポイント・マーカー線）
- [ ] 指定していない文字が勝手に入っていないか
- [ ] 文字の見切れ・重なりがないか
- [ ] 色が指定の範囲に収まっているか
- [ ] 記事の中の他の図と見た目が揃っているか
