## 変更のあらまし

### 2026-09-14（初版）

「有料note作成キット」（2026-09-12版）をもとに、講座の受講生向けに機能を絞って作りました。

**外したもの**

- 構成と本文の点数づけ（90点に届くまで自動で直す仕組み）と、点数にもとづく書き直し
- 点数づけの中で行っていた、景表法まわりの表現の点検（書くときに避ける表現のルールと、価格の工程での法律まわりの確認は残しています）
- 売れないときの診断
- 目次の自動挿入
- 図をまとめて作る機能（マーカー方式の一括生成・一括差し込み）
- 画像の種類を11から4に（残したのは見出し画像・挿入図解・人物イラスト・操作画面のスクリーンショット）
- OpenAIのAPIキーで作るイラスト
- 使い方ガイドPDF
- 画像の見本のうち、外した種類の5枚（16枚 → 11枚）
- Notionへの保存（講座生はNotionを使わない前提。止まる場所は4か所）

**変えたもの**

- **導入の質問を30問から20問に**（記事づくり8・文章と画像の好み6・あなたらしさ6）
- **置き場所を `~/yuryo-kit-live`、手順書の名前を `yuryo-live-note` `yuryo-live-image` `yuryo-live-toukou` にした。** 無料の「note記事づくりキット」や「有料note作成キット」と同じパソコンに入れても、上書きし合わない
- 利用規約を、講座の受講生ご本人の利用に限る形にした
- 質問の答えが「なし」「おまかせ」のときも欄に書き込むようにした（空欄のままだと、点検で「空です」と出るため）
- 文章のサンプルから一人称・語尾などを読み取って、設定ファイルに書き込むようにした
- **呼びかけ方・絵文字・太字・寄せたい書き手を、`profile.md` の「3-2. 文章の好み（任意）」に分けた。** 必須の「3. 文章のトーン」に任意の欄が混ざっていたため、必須の質問だけで区切ると、点検で必ず✗が出ていた
- 画像づくりの道具を入れたかどうかを、設定ファイルに書き込むようにした
- 図解の指示文のひな形を、図解の型（クリーム色の背景・カードの影・まとめ帯）に合わせた。それまでは「影なし・装飾なし」と書かれていて、型の説明と食い違っていた
- 作る人の環境にしか無い説明（別のパソコンへの引き継ぎ、Codexの動きの説明の一部）を削除
- **入稿の最後に出る「販売価格」を、価格の工程で決めた値段から出すようにした。** 値段は `article.md` の `price:` に書く。それまでは設定ファイルの「価格帯」（決める前の目安。例：980〜1,500円）がそのまま出ていた
- 部品のダウンロードで英語の注意（vulnerabilities）が出たときの説明を足した（2026年9月14日時点はテスト用の部品 vitest の2件で、記事づくりと入稿には使っていない）
- **誘導先が「なし」のとき、記事の締めに「1人だと止まりやすい場所」の一覧を置かないようにした。** 本人の7工程の文書も「セミナーにつなぐ」を「profile.md の誘導先につなぐ」に変えた
- 外した機能の名残り（CTA固定画像）と、設定ファイルに無い欄名（締めの誘導先・CTAブロック・触れない話題）を直した
- 「やめたい」と言われたときの対応を、AI向け案内書に足した
- 手順書に残っていた作者の口ぶりを直した

## 更新するとき（作者向け）

1. 直した内容を「変更のあらまし」に1行足す
2. **ファイルを消す前に、上の2つの表と突き合わせる**
3. 版の日付を書き換える
4. zipに固める前に、`node_modules` `storage` `logs` `screenshots` の中身と `.bak` を除く
5. **日本語以外の文字が紛れていないか走査する**（下のコマンド）
6. 固めたzipを展開して、`npm install` → `typecheck` → `test` → `doctor` → `dry-run` まで通す
7. もとの「有料note作成キット」を直したときは、こちらにも取り込むかを判断する（名前と置き場所が違うので、そのまま上書きしない）

```bash
grep -rlP '[\x{AC00}-\x{D7AF}\x{0400}-\x{04FF}\x{0E00}-\x{0E7F}]' \
  --include="*.md" --include="*.ts" --include="*.mjs" --include="*.html" . | grep -v node_modules
```

何も出なければ問題なし。**文章を書き換えた直後に毎回走らせる**（最後にまとめてやると忘れる）。
