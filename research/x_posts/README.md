# X(Twitter) リサーチメモ

X で見つけた有益な投稿・スレッドを、後から探しやすい形で保存する場所です。

## ファイル名ルール

`YYYY-MM-DD_トピック.md`（例: `2026-09-06_semiconductor-rally.md`）

## 書き方の例

```markdown
# 2026-09-06 半導体株の動き

## 元投稿
- URL: https://x.com/...
- 投稿者:
- 日時:

## 引用/要約
> ここに投稿本文の要点を引用・要約

## 自分のメモ
- なぜ重要か
- どの号のネタに使えそうか
```

スクリーンショットを保存する場合は同名フォルダを作り、
`YYYY-MM-DD_トピック/screenshot1.png` のように格納してください。
