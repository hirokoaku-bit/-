# published/ - note 公開実績

公開した号の記録を `publish_log.csv` に追記していきます。
過去の実績を振り返って、価格設定や反応の良かったテーマを分析するのに使います。

## publish_log.csv の列

- `issue_dir`: issues/ 配下のフォルダ名
- `title`: note のタイトル
- `publish_date`: 公開日
- `note_url`: note の記事URL
- `price`: 価格（円）
- `format`: 無料レター+有料記事 / マガジン等
- `sales_count`: 販売数（分かれば）
- `notes`: メモ（反響、反省点など）
